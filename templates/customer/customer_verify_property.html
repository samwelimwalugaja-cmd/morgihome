Verify Property Ownership

Copy the Title Number / Plot No / NAPA Code from the property posted by the seller and verify it on the official Ministry of Lands, Housing and Human Settlements portal (e-Ardhi). This confirms the title deed is genuine and valid before you proceed with your mortgage application.

How to Verify Your Property

Copy the Title Number / NAPA / Plot No from the property you want (found on Properties details page), then click the button below to go to the official portal.

Go to e-Ardhi Portal — Verify Document

Link: https://eardhi.lands.go.tz/ — Official Ministry of Lands, Housing and Human Settlements

Instructions:
  1. Copy the Title / NAPA code from the property details (e.g. NAPA-001 or Plot 123 Block A).
  2. Click the button above — a new tab will open at https://eardhi.lands.go.tz/.
  3. In the portal navigation, click Verify Document.
  4. Paste the code you copied into the field and submit — you will see the official document information and can confirm it is verified. Verification only — no need to download a certificate.
1
Copy Property Code

Go to Properties Dashboard or Public Listings → View Details → copy the Title Number / NAPA / Plot No. This is the code you will verify.

2
Go to Portal & Verify

Click the Go to e-Ardhi Portal — Verify Document button above. On the portal, click Verify Document in the navigation, then paste the code you copied.

3
View Official Information

The portal will display the official title information so you can confirm it is valid and authentic. This is a verification only step — you do not need to download any certificate. Keep the verified information for your application.

Tip: If you do not have the title code, contact the seller or Real Estate agent. MorgiHome does not store your title — verification is performed only via the official e-Ardhi system.
Alternative: You can also click e-Ardhi Login and manually choose Verify Document from the navigation menu, then enter the code yourself.
