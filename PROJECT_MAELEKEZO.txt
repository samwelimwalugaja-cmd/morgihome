   from django.contrib.auth.models import AbstractUser
   from django.db import models

   class User(AbstractUser):
       ROLE_CHOICES = (
           ('customer', 'Customer'),
           ('seller', 'Seller'),
           ('bank', 'Bank'),
           ('realestate', 'Real Estate Company'),
           ('lawyer', 'Lawyer'),
       )
       role = models.CharField(max_length=20, choices=ROLE_CHOICES, default='customer')
       phone_number = models.CharField(max_length=15, blank=True, null=True)
       is_verified = models.BooleanField(default=False)

       def __str__(self):
           return f"{self.username} ({self.get_role_display()})"

--- KAZI 1.8: Views ---
TEKELEZA:
1. Unda accounts/views.py
2. Weka:
   from rest_framework import generics, status
   from rest_framework.response import Response
   from rest_framework.permissions import AllowAny, IsAuthenticated
   from rest_framework_simplejwt.tokens import RefreshToken
   from .serializers import RegisterSerializer, UserSerializer
   from .models import User

   class RegisterView(generics.CreateAPIView):
       queryset = User.objects.all()
       permission_classes = [AllowAny]
       serializer_class = RegisterSerializer

   class LoginView(generics.GenericAPIView):
       permission_classes = [AllowAny]

       def post(self, request):
           username = request.data.get('username')
           password = request.data.get('password')
           user = User.objects.filter(username=username).first()
           if user and user.check_password(password):
               refresh = RefreshToken.for_user(user)
               return Response({
                   'refresh': str(refresh),
                   'access': str(refresh.access_token),
                   'user': UserSerializer(user).data
               })
           return Response({'error': 'Invalid credentials'}, status=status.HTTP_401_UNAUTHORIZED)

   class ProfileView(generics.RetrieveUpdateAPIView):
       permission_classes = [IsAuthenticated]
       serializer_class = UserSerializer

       def get_object(self):
           return self.request.user

USALAMA - MABADILIKO YA UKANISHO (SECURITY HARDENING)
================================================================================

LAKI ZOTE ZIMABADILISHWA KUTOKANA NA UKAGULI WA UKANISHO:

1. SECRET_KEY - Imebadilisha kuja kwenye .env si kwenye code. Key mpya imetengenezwa.
2. DEBUG - Imebadilishwa kuwa False default (True tu katika development).
3. ALLOWED_HOSTS - Imefikiria kuwa na majina ya host maalum, si ['*'].
4. CORS_ALLOW_ALL_ORIGINS - Imeibwa (False). Imetumia CORS_ALLOWED_ORIGINS badala yake.
5. DATABASE - SQLite imaaminiwa PostgreSQL (SSL mode: require).
6. PASSWORD VALIDATION - Minimum length 12, Argon2 hasher, Byte validator amaendeshwa.
7. SESSION SECURITY - Secure cookies, HTTPOnly, SameSite=Lax, expire at browser close.
8. HSTS - Imetumia Strict Transport Security (max-age=31536000).
9. X-FRAME-OPTIONS - DENY (hakuna clickjacking).
10. RATE LIMITING - django-ratelimit imeungwishwa kwenye endpoints zote muhimu.
11. BRUTE FORCE PROTECTION - django-axes imefungwa (5 attempts, cooloff 1 minute).
12. STATIC FILES - Whitenoise imefungwa (CompressedManifestStaticFiles).
13. EMAIL - Token halikusabIHI kwenye body ya barua (toka tu URL).
14. OTP - Hakuna print/log ya OTP kabisa. Tumia secrets.randbelow() si random.
15. SERIALIZERS - PII fields (nin_number, email, phone_number) zimeFIRIWA kwenye API.
16. SWAGGER/API DOCS - Public=False, inahitaji Bearer token yaweze kuangalia.
17. FILE UPLOAD - Limit 5MB, validation ya content type imefikiriwa.
18. .gitignore - Imetengwa kuzuia .env, db.sqlite3, media, logs.
19. requirements.txt - Imeandikwa version zote zimepigwa pwani (pinned).
20. ADMIN URL - Imebadilishwa kuwa 'admin-secure/' si '/admin/'.
21. CSRF - Cookie HTTPOnly, SameSite=Lax, Secure.
22. LOGGING - File ya security.log inarekodi security events.
23. PASSWORD RESET - Confirm password field imeongWIWA.
24. HTTPS - SECURE_SSL_REDIRECT, CSRF_COOKIE_SECURE, SESSION_COOKIE_SECURE.

FILES YALIBOBADILISHWA:
- .env (SECRET_KEY mpya, DEBUG=False, configuration)
- requirements.txt (version zote zimepigwa pwani)
- .gitignore (imetengwa)
- morgihome_backend/settings.py (full security hardening)
- accounts/models.py (OTP imetumia secrets module)
- accounts/serializers.py (PII fields zimeFIRIWA, password min_length=12)
- accounts/views.py (OTP halikusabIHI, rate limiting, email safe)
- api/urls.py (Swagger public=False)
- morgihome_backend/urls.py (admin URL secure, rate limit view)

FILES ZA ZIADA:

MABADILIKO YA USALAMA YA ZIADA:
25. CSP (Content Security Policy) - django-csp imeunganishwa. Headers zimefungwa.
26. CSP_EXCLUDE_URLS - Admin, Swagger, Redoc zimefungwa CSP.
27. DRF THROTTLING - Throttle rates zimeongezwa (mortgage, contract, transaction, property, search).
28. FILE VALIDATION - mortgages/views.py na transactions/views.py na identity upload zimekuwa na file size validation (5MB).
29. THROTTLE CLASSES - Zote ViewSets zina throttle_classes = [UserRateThrottle].
30. API SERIALIZERS - api/serializers.py PII fields zimeFIRIWA (email, phone_number, nin_number).
31. REGISTER SERIALIZER - confirm_password field imeONGWAA. Password min_length=12.
32. LOGIN THROTTLING - AnonRateThrottle imefungwa.
33. AXES - CacheHandler imetUMIWA kwa performance bora.

FILES YALIBOBADILISHWA (ZIADA):
